Privacy Policy

Last updated: October 2026

What this tool is

WyreSounds Uploader is a personal tool operated by its owner to upload their own videos to their own YouTube channel. It has no other users.

Data accessed

When the owner authorizes the tool with their Google account, it requests access to the YouTube Data API only to upload videos and set their title, description, thumbnail and publish schedule on the owner's own channel.

Data stored

The OAuth tokens issued by Google are stored only in the owner's private storage (the owner's computer and the owner's private repository secrets). They are used only to perform the uploads described above.

Data sharing

No data is sold, shared, transferred or disclosed to any third party. No data from other people is collected.

Google API Services

The use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

The tool uses YouTube API Services. By using it, the owner agrees to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
