# Type Beat Video Generator

App de escritorio (PyQt + FFmpeg) que genera videos de type beats para YouTube.

- El plan del proyecto está en `PLAN_AUTOMATIZACION.md`. Se trabaja una fase por sesión.
- Código nuevo va en `core/` (módulos chicos). No agrandar `main.py`.
- Antes de escribir código, mostrar un plan corto (máx. 5 líneas).
- Al terminar una fase: marcarla como completada en el plan y hacer commit.
- Entry point: `python main.py` (Windows, ver `run_app.bat`). Config en `config/app_config.json`.
